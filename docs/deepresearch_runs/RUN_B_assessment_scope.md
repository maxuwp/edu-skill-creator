## What counts as a source

Cite the original publication, its publisher, or the issuing organization: the paper itself
(including author-hosted or institution-hosted PDFs and ERIC full text), the publisher's page, the
book's official sample pages, the author's own site.

Reviews, summaries, blog posts, course pages, lecture slides, aggregator sites, mirror domains and
document resellers are pointers, not sources. Use them to find the original, but the URL you report
must be the original. A previous run of this task failed by citing a personal blog review for a
